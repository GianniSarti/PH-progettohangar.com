I file nella cartella immagini (non nelle sottocartelle)hanno lo standard: numero dell'immagine; versione dell'immagine; nome del soggetto; indicazioni (immagine campione, risoluzione); suffisso. Es: 
`3.6 PH Flotta 4K.jpg` indica che è stato usato il prompt 3, alla sesta modifica quel prompt ha creato l'immagine che rappresenta la flotta PH in risoluzione 4K e formato JPG.
